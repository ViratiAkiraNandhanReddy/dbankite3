🚀 Quickstart

  1. Clone the repository git clone https://github.com/ViratiAkiraNandhanReddy/dbankite3.git
  2. Navigate to directory cd dbankite3
  3. Install dependencies pip install -r requirements.txt
  4. Run the application python main.py
💡 Tip: On first run, the application automatically creates the SQLite database with required tables.

🛠 Tech Stack

1

Python 3.12+

Clean, readable, and beginner-friendly backend language with excellent database support.

2

SQLite3

Lightweight, file-based relational database. No server setup required—perfect for learning.

3

CLI Interface

Command-line interface for user interaction. Easy to extend with web frameworks later.

🗄️ Database Schema

dbankite3 uses a simple but effective relational design:

users

usernameVARCHAR(50) PRIMARY KEY
passwordVARCHAR(25) NOT NULL
balanceREAL DEFAULT 0

administrator

passwordVARCHAR(25)
noticesTEXT
